Welcome. In the next few minutes we'll build up an intuition for how neural networks work, starting from a single neuron and ending with why depth matters.

A neuron is deceptively simple. It takes several numbers as input, multiplies each by a weight, adds them up, adds one more number called a bias, and then runs the result through an activation function. That activation is the key ingredient — it introduces a bend, a non-linearity, so the network can represent more than straight lines.

Stack these neurons into layers and something useful happens. Early layers pick up simple patterns; later layers combine those into more abstract ones. Training is the process of tuning every weight so the network's outputs get closer to the answers we want, guided by a loss function and an algorithm called backpropagation.

To recap: many simple units, combined non-linearly, tuned by gradient descent. That's the whole idea, and everything else is refinement.
